# Futur Haïti — Laboratoires éducatifs

Portail statique qui réunit les applications éducatives de Futur Haïti : système solaire, géologie, chimie et histoire.

## Déploiement Vercel

Importer ce dépôt dans Vercel avec les réglages suivants :

- Framework : **Other**
- Build command : laisser vide
- Output directory : `dist`

Le site ne nécessite ni installation de dépendances, ni variable d’environnement. `index.html` est le fichier source; `dist/index.html` est la version servie en production.

Les estimations de progression affichées sur les cartes décrivent l’état de la première version et peuvent être ajustées au fil du travail.
